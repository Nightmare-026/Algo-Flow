# Algo Flow

Welcome to **Algo Flow**! An interactive, dynamic, and visually stunning Data Structures and Algorithms visualizer.

## 🚀 Live Demo

**Play with the live application here:** [https://algo-flow-night-sigma.vercel.app/](https://algo-flow-night-sigma.vercel.app/)

*(Note: If you see any other `.vercel.app` links on GitHub, please ignore them as they are outdated.)*

## 🛠 Features

- **Interactive Visualizers:** Step-by-step visualization for Arrays, Strings, Matrices, Trees, and Graphs.
- **Modern UI:** Built with Next.js 16, Tailwind CSS v4, and React Flow for an immersive, premium glassmorphism design.
- **Authentication:** Sign up and log in via Email, Google, or GitHub (Powered by Supabase).
- **Progress Tracking:** Save your sessions, track streaks, and bookmark your favorite algorithm visualizers.

## 💻 Getting Started Locally

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## ⚙️ Tech Stack
- Framework: Next.js (App Router)
- Language: TypeScript
- Styling: Tailwind CSS
- Authentication & Database: Supabase
- Interactive Canvas: React Flow
- Icons: Lucide React
